# agents-hw1 · ДЗ1 «Одна задача. Два способа разработки»

Факультатив «Создание ИИ-агентов с нуля», ФКН НИУ ВШЭ.
**Вариант:** A (новичок) · **Автор:** Софья Акимова · **Модель:** Claude Opus 5.5 (`claude-opus-5-5`) · **Дата:** 16.11.2026

Мини-трекер учебных задач, сделанный двумя способами: коротким прямым запросом (v1) и через спецификацию в формате OpenSpec (v2, без CLI).

**Отчёт:** [`report.md`](report.md)

## Как запустить

Скачайте нужный HTML-файл и откройте его двойным кликом в браузере. Сервер, установка и интернет не нужны.

| Файл | Что это |
|---|---|
| `tracker-v1.html` | Попытка 1, прямое задание. Исходная версия, до исправлений |
| `tracker-v1-fixed.html` | Попытка 1 после одного исправления (границы 0,5–24 и шаг 0,5) |
| `tracker-v2.html` | Попытка 2, реализация по спецификации |

Задачи сохраняются в localStorage. Чтобы вернуть стартовый пример, очистите данные сайта (DevTools → Application → Local Storage).

## Структура

```
prompts.txt                 тексты всех промптов (запрос, спецификация, реализация, исправление)
report.md                   отчёт: учёт обращений, T1–T5, «до → после», вывод, ограничения
spec/                       спецификация v2 в формате OpenSpec (без CLI)
  proposal.md
  specs/tracker/spec.md
  design.md
  tasks.md
chat-logs/                  полные ответы модели в обеих попытках
screenshots/                скриншоты проверок
checks/                     скрипт проверок T1–T5 (Playwright + Chrome) и реальные логи прогонов
```

## Повторить проверки

```
pip install playwright
python checks/run_checks.py v2 tracker-v2.html screenshots v2
```

Скрипт рассчитан на Chrome по пути `/usr/bin/google-chrome`. На другой системе поправьте `executable_path` в `run_checks.py` или выполните `playwright install chromium` и уберите этот параметр.
